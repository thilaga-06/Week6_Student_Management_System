# Student Management System

## Project Description
The Student Management System is a console-based Java application used to manage student records.

## Features
- Add a student
- View all students
- Search for a student by ID
- Update student details
- Delete a student
- Save and load student records using file handling
- Generate a student report using multithreading
- Validate user input and handle errors

## Technologies Used
- Java
- IntelliJ IDEA
- ArrayList
- File Handling
- Multithreading
- Interface and Object-Oriented Programming

## Project Structure
- `Main.java` — Main menu and student management operations
- `Student.java` — Student data and methods
- `RecordOperations.java` — Interface for displaying student records
- `StudentReportTask.java` — Background report generation
- `students.txt` — Stores student records when the application runs

## How to Run
1. Open the project in IntelliJ IDEA.
2. Ensure all Java files are inside the `src` folder.
3. Run `Main.java`.
4. Follow the console menu instructions.

## Menu Options
1. Add Student
2. View All Students
3. Search Student
4. Update Student
5. Delete Student
6. Generate Student Report
7. Exit

## File Storage
Student records are saved in `students.txt` and loaded when the application starts.
